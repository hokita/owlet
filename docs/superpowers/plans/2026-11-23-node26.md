## Risks that apply

1. **A pin is missed or the script default isn't moved with it.** `check-node-pins.sh` checks the 3 `FROM`s, all `node-version:` lines and 3 Volta pins, with exact counts; Task 1 runs it red first, then green. Task 3 makes CI enforce it.
2. **Native/ABI-bound deps break on ABI 147.** Only `re2` (optional, e2e only) is native; esbuild/rollup/lightningcss/oxide ship per-platform binaries not tied to the Node ABI. `npm ci` on 26 locally (darwin-arm64) and in CI (linux-x64), and in the Docker build (linux, alpine/musl) catches it.
3. **Node 26 semver-major changes reached through transitive deps** (`_stream_*` and `http.writeHeader` removed, Undici 8 under global `fetch`, `localStorage` returns undefined without a file, extensionless-CJS exception removed for `"type":"module"`, `module.register()` runtime-deprecated). Not ruled out by grep. The backend Vitest suite (incl. MCP-over-HTTP via `fetch`), the frontend jsdom suite, builds, the container smoke run and Playwright E2E (auth + Firestore emulators, real Express + Vite) exercise these paths.
4. **New base image has HIGH/CRITICAL CVEs**, so CI `image-scan` (Trivy) goes red. Then follow systematic-debugging; fix by cause (as in the 2026-11-22 plan), and stop and report if no fix exists.
5. **Deploy rolls out but Cloud Run keeps serving the old revision, or the nightly runtime check disagrees with what's deployed.** Covered by the post-merge checks.
6. **Lockfile churn from npm 11.20.0.** Only `backend/package-lock.json` changes, and only for `@types/node` (+ `undici-types`). Check the diff in Task 1.
7. **After merge, your own checkout makes Volta fetch 26.13.1** the first time you run npm in owlet. That's the Volta pin working as designed, but it's a Mac change only you can approve. This PR doesn't trigger it.

## Changes during execution (2026-11-23)

- **Vitest 4 → 5.1.1 (frontend and backend), user decision.** On Node 26, 115 of 223 frontend tests failed. Node 26 defines its own `globalThis.localStorage`, which is `undefined` without `--localstorage-file`. Vitest 4.1.12 keeps globals that already exist, so jsdom's `localStorage` never reached the tests (`Composer.tsx` uses it; the Scope grep above missed it because its output was truncated). Vitest 5 replaces the Node global. The backend moved too so both packages run the same major.
- **npm 11.20.0 blocks dependency install scripts** that `package.json` `allowScripts` doesn't list (esbuild, fsevents, protobufjs, `@firebase/util`, re2). No `allowScripts` was added: tests, builds, the image and E2E all pass with the scripts skipped, and `@firebase/util`'s script only acts when `FIREBASE_WEBAPP_CONFIG` is set, which owlet doesn't do. Installs print an `install-scripts` warning.
- **`format:check` order.** Prettier in a package dir doesn't read the root `.prettierignore`, so it flags `dist/` after a build. Task 4 runs `format:check` before `build`.
